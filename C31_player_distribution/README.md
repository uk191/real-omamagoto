# C-3.1を起動する

[起動パック C31_START.zip](https://github.com/uk191/real-omamagoto/raw/refs/heads/c0-player-download/player-download/C31_START.zip) をすべて展開し、`START_C31.cmd` を開く。初回は確認済み本体約103MBを取得し、旧C3とは別のフォルダへ用意する。旧フォルダの指定は不要。

年齢・学歴・地域を指定して家庭を生成し、普段の方針を選ぶ。自動進行し、四択の相談では止まる。B（遊び）は4か月、A（外出）は8か月、C（仕事と家の時間）は12か月、D（架空の写真企画）は16か月頃。約二か月後に実際の選択を踏まえた相談が戻る。求人など現在の家庭事情や実行条件に応じて変わる。4倍速にもできる。選択後の結果を見て「暮らしに戻る」で再開し、終了前に保存する。

[本体全体ZIP](https://github.com/uk191/real-omamagoto/raw/refs/heads/c0-player-download/player-download/C31_PLAY_WINDOWS_X64.zip)／[コード・資料・画面](https://github.com/uk191/real-omamagoto/raw/refs/heads/c0-player-download/player-download/C31_CODE_AND_REPORTS.zip)／[全分岐データ](https://github.com/uk191/real-omamagoto/raw/refs/heads/c0-player-download/player-download/C31_COMPARISON_DATA.zip)／[保存後の検査](https://github.com/uk191/real-omamagoto/blob/c0-player-download/player-download/C31_RELEASE_VERIFICATION.json)。

旧版と旧セーブは残る。新規家庭で四つの相談を評価することを推奨する。旧C3を継続する場合は元セーブの.json.gzと同名.meta.jsonを新しいsavesへコピーできる。操作時点までの旧選択は残り、新しい相談は読込後から発生する。

Windowsの実機実行は未検証。Linux Chromiumでの二家庭24か月とPowerShellでの準備処理は別途検査している。支払い口座は世帯の通貨性預貯金であり、年齢と資産の同時分布は未校正。今回、任意の貯蓄上限は加えていない。面白さの最終判定はプレイヤー本人による。
