# C-0 Windows player download

Existing C-0 prototype, packaged for local player feedback. No C-0.1 game feature development or simulation-model change.

Download `C0_PLAY_WINDOWS_X64.zip` from this directory, extract the entire ZIP, and double-click `C0_Play/PLAY.cmd`. A browser opens automatically. Python and the required libraries are bundled; no separate installation is needed. Windows 10/11 x64 only.

Before closing the startup window, save in the game. On the next launch, select the saved record in the browser.

Cloud/Linux browser checks cover household generation, observations, decisions, 24-month progression and save/load across an actual server restart. Windows binaries were verified against official hashes and statically checked, but not executed on a Windows machine.

The ZIP contains application code, compiled statistical inputs, and Windows runtime dependencies. It contains no development save slots or logs. Licenses and Japanese instructions are included.
