# C-1 フォルダ選択後エラーへの起動経路修正

ユーザーから「フォルダを選んだあと」にエラーとの報告があった。エラー本文は取得できていないため、選択場所・旧版の依存ファイルのSHA不一致・書込権限・適用後の起動のどれが直接原因かは未特定。原因を確定したとは表現しない。

既存の更新器は旧配布の186依存ファイルの一致を確認し、不一致なら停止する設計であった。この検証を緩めずに、フォルダ選択や旧版の内容へ依存しない、別の起動補助を追加した。

- `C1_SAFE_START.zip` の `START_C1.cmd` を実行する。
- 固定された公開コミットd3317e50a7a2ea2f74a72b1f4843248e6c34ce4eのC1本体を使用。SHA256 4f65d84579be58767f51b4b67cd71c2364273225882961602671968a886761b5。
- 既存の正式ZIPをダウンロードフォルダ等から再利用できる。なければHTTPSで取得し、ハッシュを確認する。
- ローカルアプリデータのRealOmamagoto/C1配下へ展開する。旧C01を選ばず、変更しない。
- 展開後の4,134ファイルを固定マニフェストに照合する。次回起動も全ファイルを検査し、破損・不足があれば既存C1とセーブを保管して修復する。
- Pythonとライブラリのロードを確認してから起動する。標準出力・標準エラー・終了コードをファイルへ保存する。失敗時はstartup-error.txtをメモ帳で開き、親ウィンドウも閉じない。
- Windows実行ポリシーや管理者設定の変更を要求しない。ゲーム本体・A/Bモデル・統計・セーブ形式は変更しない。

Microsoft公式配布のSHA256を確認したPowerShell7.4.7をLinux上で使い、実際の埋込スクリプトの展開・キャッシュ再利用・Python欠落の修復・JS破損の修復・旧セーブと退避先の保存・不正ZIPの拒否とエラー記録・大きな標準エラー出力の捕捉を検証する。検証結果はC1_SAFE_START_VERIFICATION.json。Windowsのcmd.exe、メモ帳、ネイティブpython.exeの実機実行とは区別する。

今回の起動補助でユーザー環境の実際のエラーが解消したかは、ユーザーが実行するまで未確認。引き続き失敗する場合は自動で開いたエラー記録をもとに、具体的な失敗箇所を修正する。
