# C-1 をプレイする

フォルダ選択後にエラーになる場合は、**[フォルダ選択不要の起動パック（約5KB）](https://github.com/uk191/real-omamagoto/raw/refs/heads/c0-player-download/player-download/C1_SAFE_START.zip)** をすべて展開し、`START_C1.cmd` を開いてください。初回は確認済み本体約103MBを取得し、別フォルダへ自動展開します。旧ゲーム・旧セーブは残ります。次回も同じ起動ファイルを使えます。

起動の失敗は `RealOmamagoto/C1/startup-error.txt` に保存してメモ帳で開きます。内容を確認してからチャットへ送れます（自動送信なし）。

以下は原本と完全一致する旧版がある場合の従来手順です。フォルダ選択後のエラーが出た方は上の起動パックを使ってください。

[従来の小さな更新パック](https://github.com/uk191/real-omamagoto/raw/refs/heads/c0-player-download/player-download/C1_UPGRADE.zip)がおすすめです。

1. ZIPを「すべて展開」し、`UPDATE_C1.cmd` を開く。
2. 現在のゲームの `PLAY.cmd`・`runtime`・`app` があるフォルダを選ぶ。
3. 検証後、追加された `PLAY_C1.cmd` からプレイする。

旧ゲームと旧セーブは残ります。C-1のセーブは `saves_c1` に分離します。原本の版が異なる場合は更新しません。

初めて入れる方・更新が合わない方は、[全体ZIP](https://github.com/uk191/real-omamagoto/raw/refs/heads/c0-player-download/player-download/C1_PLAY_WINDOWS_X64.zip)を別のフォルダへすべて展開し、`C1_Play/PLAY.cmd` を開いてください。

[ソース・資料・検証記録](https://github.com/uk191/real-omamagoto/raw/refs/heads/c0-player-download/player-download/C1_CODE_AND_REPORTS.zip)、[SHA256](https://github.com/uk191/real-omamagoto/raw/refs/heads/c0-player-download/player-download/C1_SHA256SUMS.txt)、[保存後の検証結果](https://github.com/uk191/real-omamagoto/raw/refs/heads/c0-player-download/player-download/C1_RELEASE_VERIFICATION.json)も公開します。

父親として遊びや外出を予定に入れ、勤務や分担を相談してください。初めは「声かけ」、成長後は「絵本」「公園」、繰り返す予定が試せます。1か月は標準約10秒、24か月まで進みます。保存は終了前に行ってください。

活動の短期反応と配偶者の会話は未校正の体験シナリオです。能力・愛着への長期効果は追加していません。旧A/B統計モデルの制約も残ります。Linux上のブラウザ検査とWindows実機検査は区別しています。実際の面白さは、ユーザーのプレイで評価していただく段階です。
