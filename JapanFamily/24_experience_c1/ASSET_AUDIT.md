# 初期人物・資産の監査

今回、検証済みC-0.1公開パックをSHA256とZIP CRCを照合して復元した。父親の資産を新しく推定する変更や、A研究モデルの係数変更は実施していない。

| 項目 | 実装上の意味 | 根拠・未確認事項 |
|---|---|---|
| cash | 世帯の通貨性預貯金。支払いに使う口座 | 紙幣・硬貨のみでも、全金融資産でも、父親個人の財産でもない |
| term | 世帯の定期性預貯金 | 通貨性との保有・配分の同時分布は未確認 |
| securities / insurance_reserve | 有価証券 / 保険準備金 | 金融資産。支払い口座に合算しない |
| home / other_property | 現在の住宅 / その他不動産等 | 現金として使えない。住宅・負債との完全な整合は未検証 |
| L:mortgage / L:other_debt | 住宅・土地 / その他借入 | 不動産の対象は必ずしも現在の家と一致しない |
| AR / L:AP | 未収金 / 未払金 | 給与の入金待ち等。現金と区別して純資産を算出 |
| net worth | 全資産・債権−全負債・未払金 | A16の旧純資産参照値を口座へ強制的に合わせていない |

`16_recovery/model.py::assets` は2024年の住宅ローン保有・可処分所得帯・参照世帯規模別の保有確率・平均を使う。金額分布の形は `15_initial_state/data/state_kernels.json::asset_holder_quantiles`、元表 `finance_7-101-1`、シートF71011等。各分位点の行・列・原値が核に保持されている。`15_initial_state/compile.py` は原表の千円を1000倍して円へ変換する。例えば原値3800→3,800,000円であり、今回の検査範囲で単位の1000倍誤りは見つからなかった。

高額残高の主な問題は、**出生家庭に対して全年齢世帯の資産分布を移送し、親の年齢・職業・所得・住宅・負債の完全な同時分布を識別していないこと**。金額形状と所得の同時分布、成分相関rho=.5、裾の外挿、預金配分はいずれも仮定を含む。年齢に応じた蓄財モデルや相続・贈与の履歴は存在しない。したがって「若い頃から貯めた」「相続した」等の説明を生成しない。居住人数と資産表の参照世帯規模も一致するとは限らない。

例：seed1301、父32歳・母30歳の参照家庭は、父通常年収4,165,038円、母3,084,947円、実居住3人に対し資産選択は参照size:4。支払い口座0円、定期性預貯金23,583,138円、保険準備金3,716,123円。これは不自然な組合せを生成しうる実例であり、2026年出生家庭に適合した初期状態とは判定しない。

C-1では「世帯の支払い口座」と明記し、開始確認と詳細で資産別残高・負債・純資産を分離する。個人の持分は未識別。開始口座を指定した場合は、Aの既存 `initial_cash_override` による明示的シナリオであり、他資産・負債まで校正されたとは扱わない。無断の上限切捨てや年齢係数は導入しない。

人物の年齢は出生統計、学歴・職業・通常所得は2022年就業構造等の条件付き参照。所得帯内の点値は抽選・割付であり観測値ではない。職業×産業×年齢×所得や住宅・資産との完全な同時分布は未観測。人名はユーザー入力または架空名、過去の経歴はユーザー入力か「未設定」。現在の通常年収と、育休・実働・実際の入金を区別する。

優先バックログ：出生家庭・年齢階級別の保有確率と分位点、所得・住宅・借入との同時分布の再取得、個人持分の設定方法、資産表の参照規模と実居住人数の整合。C-1の画面修正によって、これらの統計的問題が解消したとは宣言しない。
