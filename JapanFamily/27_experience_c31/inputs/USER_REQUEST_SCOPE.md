# 最新依頼の作業範囲（要約、逐語原文ではない）

C系統改善第1弾。現行C3を保全し、家族生成・時計・停止・再開・時系列・状態・保存・A/B接続の回帰検査。重要な強制選択は四つの異なる価値観で、A経験、B興味成長、C仕事金家族時間、D予想外の機会の四イベントのみ徹底的に完成する。具体的な家庭の背景から発生し、時間・金銭・人物・子の経験と反応・家族の記録・後続条件・未実現理由を保存。少なくとも一つの後続イベントで選択→経験→記憶→新しい出来事を示す。全16分岐を同じ各チェックポイントから実行し、直後と1〜3か月後を比較。異なるseedと家庭でも検査。

父23歳・母22歳で1,000万円超の貯蓄が出る件を緊急監査。正式A API、学歴の反映、所得直接入力の由来、資産区分、年齢所得住宅負債の整合を調査。UIミスは修正し、任意資産上限などの統計改変はしない。通常は年齢・学歴・地域から職業所得を統計生成する。抜本的な家計改修は次工程とする。

他の機能をむやみに増やさず、動く更新版・16分岐・後続・状態比較・起動手順・監査・回帰結果を保存。最終的な面白さはユーザー本人がプレイして評価する。過去に公開GitHubでのゲーム配布を明示許可済み。現行A/Bの未識別効果や因果・統計限界を実証済みとして扱わない。
