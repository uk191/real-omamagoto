# 「まいにちの、あいだ。」C-0.1 P0

C-0への実プレイ評価を受け、操作・観察・意思決定の体験層を作り直した版です。A/Bの科学モデルと旧C-0は保持しています。

## Windowsで遊ぶ

1. [起動用ZIP](https://github.com/uk191/real-omamagoto/raw/refs/heads/c0-player-download/player-download/C01_P0B_START_HELPER.zip)を取得。
2. 中の `START_C01.cmd` を開く。初回は本体を取得し、SHA256確認・自動展開後にブラウザを開きます。
3. 家庭条件を選んで「この家族の暮らしを始める」。10秒で1か月の自動進行が始まります。
4. 相談が出ると停止。選んでから「この方針で自動進行を再開」。選択肢がまだあれば、続けて確認してください。
5. 終了前に右上の「保存」。次回は「保存した記録から」で再開します。

Windows 10/11 x64用。Pythonは同梱。PowerShellの実行ポリシーやセキュリティ設定を変更しません。旧C-0とは別の `RealOmamagoto/C01` へ保存します。旧版のセーブは旧版で開けます。自動移行はしません。

ネットワーク不要で遊べる[本体ZIP](https://github.com/uk191/real-omamagoto/raw/refs/heads/c0-player-download/player-download/C01_P0B_PLAY_WINDOWS_X64.zip)もあります。こちらは全体を展開してから `PLAY.cmd` を開いてください。初回取得以外のプレイ通信は自分のPC内だけです。

## 操作

通常は一画面。中央が生活ログ、左が家族と気づいた成長、右が相談と家計です。0.5/1/2/4倍速、一時停止、手動月送りができます。基本10秒に月次計算の処理時間が加わります。ページを閉じている間は進みません。

通常進行で各期1〜3件のログを追加します。親が明示的に観察を追加した場合、その記録は別に増えます。生後24か月の誕生日まで進み、月途中出生では最後の未決算期間を家計確定済みと扱いません。

家計の入金・支払いは現金移動。定期性預金等からの振替、借入、発生ベースの収入・支出とは分けます。現金がなくても未払いを消しません。詳細画面で内訳とログの根拠が読めます。

## 開発環境

既存チェックアウトを利用し、既存の未追跡資産・巨大DBを保持してください。新しいチェックアウトや旧DB再構築は不要です。

```sh
cd /workspace/real-omamagoto
bash JapanFamily/23_experience_c01/scripts/start.sh
```

Python 3.12、numpy 2.3.5、scipy 1.17.0。地域DBは既存原本、または旧C-0の `22_experience_c0/data/runtime_region.sqlite` を使います。前面実行は `python JapanFamily/23_experience_c01/server.py --port 8783`。

```sh
python JapanFamily/23_experience_c01/scripts/verify_experience.py
python JapanFamily/23_experience_c01/scripts/browser_p0.py
python -m unittest discover -s JapanFamily/22_experience_c0/tests -v
```

ブラウザ検査はsystem Chromium `/usr/bin/chromium` と既存Playwrightを使い、8783の起動済みサービスを検査します。本格的な実ユーザーテストではありません。

開始日の制度スナップショットの都合から、出生日は2026年8〜11月に制限しています。

## 実装範囲

- 家庭生成はAの条件付き生成。居住環境は市町村人口密度のゲーム用分類で、完全な家庭を棄却抽出し、住宅・所得を後からすり替えません。生成できない条件はエラーにします。
- 所得は通常年収の条件であり、当月の手取りや就業の成功を保証しません。現金の明示指定はプレイヤーが設定した開始シナリオです。
- 児童手当、保育申請、親族支援、時短・復職相談、求職・求人受諾、生活費・流動性の方針を、状況に応じてネイティブAへ送ります。
- 関わりの選択はBの観察を追加。能力・愛着への未識別の長期効果は適用しません。
- 子どもの場面は親の観察結果に基づきます。親の呼び名、居間、小物、時刻等は演出で、ログごとに記録しています。性格診断、内面数値や未観察の能力は表示しません。
- 健診実測、離乳食、病気、突発修理費、投資運用、住宅購入等は今回の操作対象に追加していません。

未校正の行動・就業・保育・家計を完成した現実予測とは扱いません。詳しくは `BUILD_REPORT.md` と `reports/`。
